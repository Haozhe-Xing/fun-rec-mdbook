当生成式推荐（参见 1.1、5.3）让模型学会「直接生成」物品序列后，一个更本质的问题浮现：模型**真的在思考**吗？传统推荐模型只是隐式打分或隐式生成的「黑箱」，我们既不知道它依据哪些信号做判断，也无法向用户解释「为什么推荐这个」。本部分沿「从表征到推理、从模仿到自主」的递进逻辑，展示让推荐系统真正「会思考」的三步跃迁。

我们先解决**语义鸿沟**：推荐的物品用协同过滤学来的离散 ID 表示，而大语言模型（LLM）理解的是自然语言——两者之间存在根本隔阂。LC-Rec 与 PLUM 用层次化量化把物品变成「既能被 LLM 理解、又承载协同语义」的语义索引。接着，OneRec-Think 在这个基础上让模型**先思考再推荐**，生成显式的、可审查的推理链。最后，RecZero 与 RecOne 探索**自主推理**：摆脱人工模板，让模型仅凭任务反馈自主演化思考策略。

## Tips for This Part

1. **把语义索引当作「翻译层」。** 它是连接协同世界与语言世界的桥梁，后面所有推理都建立在它之上。

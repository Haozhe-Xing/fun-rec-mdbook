推荐系统是现代互联网最核心的基础设施之一，但其内部逻辑远比「帮用户找内容」复杂。本部分先帮你建立 **立体的认知框架** ：从微观的两种范式，到工业的两条技术路线，再到宏观的生态平衡；最后再落到工程底座，理解业务字段如何变成模型可用的特征与 Embedding。

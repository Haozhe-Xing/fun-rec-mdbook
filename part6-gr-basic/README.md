生成式推荐正在把推荐系统从「对候选集打分排序」的判别范式，转向「直接生成推荐结果」的生成范式。这一转变不止是模型结构的更新，更是建模思路的根本革新。本部分作为「生成式推荐主线」的起点，系统搭建四大基础支柱：从**范式动机**（为什么需要生成式），到**架构基石**（用什么模型实现生成），再到 **LLM 建模流程**（如何训练这类模型），最后落到 **Tokenizer 技术**（推荐数据如何适配生成模型接口）。四根支柱层层递进，共同构成理解后续章节——从 Scaling 架构到端到端生成、从会思考的推荐到扩散模型——所必需的完整基础。

## Tips for This Part

1. **先看动机再看技术。** 6.1 的「为什么需要生成式」是理解后续一切技术的钥匙——每个技术都在回应某个判别式局限。
